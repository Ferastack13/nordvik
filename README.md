# Nordvik

Premium multi-page website for **Nordvik** — a Scandinavian furniture and interior design brand.

## Pages

- `index.html` — Home
- `furniture.html` — Catalog by room
- `product.html` — Signature product detail (Fjord Sofa)
- `collections.html` — Collection stories
- `inspiration.html` — Editorial magazine
- `about.html` — Brand heritage
- `contact.html` — Showrooms & consultation

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

Then visit the local URL shown in the terminal.
